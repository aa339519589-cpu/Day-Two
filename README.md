# Day Two

不卖社交，卖深度沟通。

这是一个移动端优先的 Web App，用来让已经认识的人继续说话。第一版是本地演示：没有账号服务器，照片和对话不会离开这台设备。

临时品牌名在 `src/brand.ts`。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端里的地址。手机和电脑在同一网络时，可以用终端里的 Network 地址打开。

```bash
npm test
npm run build
npm run preview
```

## 现在能做什么

- 产品介绍页，以及三个好友席位
- 双方同意后建立关系，退出关系不会自动删除聊天
- 抖音式纵向照片流：一次一张，上滑下一张，下滑上一张
- 从相册上传照片，保存在这台浏览器里，并出现在自己的日常流
- 针对某张日常照片回复，进入对应聊天，并带上照片
- 文字和图片消息
- 每日交流约定的开启、模拟对方同意、暂停、恢复、结束，以及连续记录
- 浅色 / 深色 / 跟随系统
- 可添加到主屏幕的 PWA

## 还没有接入

- 真实账号、数据库和对象存储
- 跨设备同步和实时聊天
- 照片的服务端访问控制。演示里他人的照片是随网页公开的静态文件；你自己上传的照片只在本机 IndexedDB 中
- 损失厌恶、会员和匹配算法

预置好友不会真实回复。需要对方同意的动作，都写明了「在这台设备上模拟」。
